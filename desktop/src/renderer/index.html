    Setup repo

    Tạo repo mới, clone repo của team hoặc mở repo có sẵn, rồi cài Taigent vào repo: các skill Taigent, MCP server taiga, bộ chạy headless và devDependency taigent, cùng version với ứng dụng. Ứng dụng không cài agent CLI giúp bạn: nó chỉ cho biết công cụ nào còn thiếu và lệnh cài.

    1. Repo

    Thư mục chứa repo Chưa chọn
    Repo có sẵn

    2. Cài Taigent vào repo

    3. npm install

    Cài taigent (devDependency mà bước 2 ghim theo version của ứng dụng) vào node_modules/, nơi agent chạy MCP server taiga. Cần Node.js 24+ trên máy.

    4. Kiểm tra

      Settings

      Đăng nhập hoặc đăng xuất Taiga bằng nút ở góc trên bên phải.

      Giao diện

      Màu của ứng dụng. Theo hệ thống đổi theo chế độ sáng/tối của Windows hoặc macOS.

      Agent cho nút chạy skill

      Agent mà các nút Plan backlog từ spec, Nhờ agent xử lý góp ý và Tạo user story dùng (run-skill headless). Ứng dụng không cài hay đăng nhập agent giúp bạn.

      Phiên bản

      Không có mục nào khớp.

      Chưa có tab nào. Bấm + trên thanh tab để mở terminal hoặc agent (claude, codex, omp), hoặc bấm đúp vào chỗ trống của thanh để mở shell mặc định. Tab chạy ở thư mục repo đang mở.

      Đăng nhập Taiga

      Mật khẩu chỉ gửi tới Taiga một lần để lấy token; ứng dụng không lưu mật khẩu. Token được cất trong kho thông tin đăng nhập của hệ điều hành, dùng chung với taigent login.

      Tạo user story

      Tả nhu cầu trong một câu. Agent soạn story theo user story format vào backlog.yaml rồi dừng ở bước hỏi xác nhận: story ở lại trong manifest để bạn review rồi đẩy lên Taiga trong ứng dụng.
